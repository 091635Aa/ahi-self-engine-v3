### 1.2 缺的是「评估意识」的另一半：注意图式

- **理论上的"评估意识"**= 系统能评估**自己**、能建模**自己的注意过程**，并据此调节行为（专家03 §2.1 line 66-69 三层定义；p3 文档 line 6：「一个系统有自我意识，当且仅当它构造了关于自身**注意**这一过程的模型，且该模型在因果结构中占真实位置」）。
- **两个内核的对照**：
  - 预测**状态**（ġ，已有）：回答"外界把我改成了什么样"。
  - 预测**注意**（ĝ_att，缺失）：回答"我下一步**盯住什么/往哪使劲**"。
- **现状核实**：
  - P1（真）：meeting39/42 的内核 .py 中无任何"预测自己下一步注意"的机制。`内核_自我回路.快拍` 只是把 `注意` 当**当拍字段**写入 `À_t`（`内核_自我回路.py:93-94`），`À_t` 再从 `A = Φ_act @ a星` 取注意（`内核_自我回路.py:225-226`）——**是记录，不是预测**。
  - 这是**"评估意识"缺一半**：只回答了"我是什么样"，没回答"我注意得对不对/往哪变"。专家03 §2.3 line 84-89 已把"想什么/想多深"钉在 `ε_att` 上——但它从未落地。
  - 出口层（P4）也印证：`输出层.读内态` 只读 `ε_self/自指束一致度/念头流动/顿悟`，**没有注意图式一路**。

### 1.4 既有 AST 先例（brain.py）踩过的坑 —— 我们必须绕开

## 2 注意图式的可操作定义（纯 HDC · 零梯度 · 确定性）

### 2.1 注意空间是什么（引擎既有候选，按可用性排序）

引擎每拍在 `rec` 里已经产出候选（`v2_engine.py:314-316`）：`a星`、`a星序号`、`候选ê`。逐一评估：

| 候选 | 源码 | 是否用 | 理由 |
|---|---|---|---|
| `a星`（被选中的动作向量）→ `A=Φ_act@a星` | `v2_engine.py:314`；`hdc_core.py:482`；恒定投影 `Φ_act` 见 `hdc_core.py:162,273` | **主路（推荐）** | 与 `内核_自我回路.py:225-226` 已用式**逐字同构**；1024 维母语空间**丰富态**；零新增投影 |
| `动作候选` 库 `{零}∪{±单位轴×4}`（K=9） | `hdc_core.py:206,215-223` | 注意码本的基 | `A_t=sign(Φ_act@a星_t)` 实际把 9 个候选映成 9 个双极码（**注意码本**） |
| `候选ê`（每候选自由能，9 维） | `v2_engine.py:315`；`hdc_core.py:454-466` | **退化对照臂** | 低维（9）；用来**实测理论②"5 维摘要退化"**方向（见 §3） |

**结论**：注意空间 = 引擎既有**动作自由度 Φ_act 张成的 1024 维母语子空间**；注意码 `A_t = sign(Φ_act @ a星_t)`（双极，与 `H双极=sign(H)` 同尺度，`hdc_core.py:484`）。
**专业词翻译**：这里"注意"= **这个引擎里唯一的"候选间竞争 + argmin 选择"过程**（`hdc_core.py:454-482` 先算 ê 表、再 `efe选i` 选中）——即**"选谁去使劲"**。不是脑的神经增益 `g_t`（那是 `brain.py` 那套才有的），本引擎的注意是**选择型**（见 §6 诚实边界）。

### 2.2 `Â_{t+1}` 怎么算（HDC 线性联想记忆，零梯度）

```
键   k_t   = sign(S_t) ⊛ sign(A_t)          # 自态 ⊛ 当拍注意（双极按位乘 = HDC 绑定；两输入均 ±1）
值   A_{t+1} = sign(Φ_act @ a星_{t+1})       # 下一拍实际选中的注意码（真值，见 2.3）
记忆 W_att ∈ R^{D×D}  （D=1024，零初始化，惰性按 D 建）
预测 Â_{t+1} = sign(W_att @ k_t)             # 绝对读出（与 ĝ 同款；禁用残差读出——内核_自模型.py:31-35）
误差 ε_att   = 1 − cos(Â_{t+1}, A_{t+1})     # ∈[0,2]，对真值算，完全自监督
更新 W_att  += (η·ε_att) · outer(A_{t+1} − Â_{t+1}, k_t) / (k_t·k_t)   # NLMS 同构
范数 W_att  ← W_att · (1.0 / ‖W_att‖)        # 有界（内核_自我回路.py:119-134 的有界修复，防时间污染）
```

- `η = ETA_R = 0.1`（`内核_自模型.py:51`，复用既有预注册步长，**零新超参**）。
- **键必须含自态 S_t**：这是绕开 §1.4 坑 2（拷贝基线）与坑 1（对动作建模）的关键；只给注意本身会退化成拷贝。
- **读出用绝对**：残差读出的教训（`内核_自模型.py:31-35`）在注意通道同样适用（残差项量级远小于双极自态，会被钉在拷贝上）。
- **全部 ±1 双极、纯乘加、无 `lstsq/solve/pinv/inv`**，确定性（C13）；同 seed ⇒ 逐位同。

### 2.3 ε_att 的"真值" `A_{t+1}` 怎么从"实际发生"里取

- **口径**：下一拍 `_引擎步` 返回 `rec` 后，取 `rec["a星"]`（`v2_engine.py:314`）→ `A_{t+1}=sign(Φ_act@a星_{t+1})`。这是引擎**自己实际选了哪个注意**，**无外部标签**——与 ε_self 的自监督同律（`内核_自模型.py:115`）。
- **时间因果（硬约束）**：`Â_{t+1}` 只许用 **t 及之前**的量（`S_t, A_t, k_t`），**不得**读 `a星_{t+1}`/`A_{t+1}`（否则泄露，判据作废）。对齐既有 `内核_真学习.py:16-17` 的 t−1 因果纪律。
- **取真值的时机**：在 `_引擎步` 返回后、**下一拍**再结算上一拍的 `ε_att`——与 ĝ 的 `学一拍(键k, 状态S)` 一脉（`内核_自模型.py:94-98`：用上拍键预测本拍状态）。

### 2.4 不硬编码阈值（自归一）

- `ε_att` 的"大/小"用**自身慢 EMA 基线** `ε_att_slow`：`ε_att_slow += α·(ε_att − ε_att_slow)`，`α = ALPHA_SLOW = 0.005`（`m2_intrinsic.py:19`；与 `内核_真学习.py:85` 的 `ε_slow` **逐字同构**）。
- "异常量" = `max(0, ε_att − ε_att_slow)`；深度/是否多想 ∝ 该**相对量**（专家03 §2.3 line 87-89、§2.4 line 95）。
- **禁止形态**：`if ε_att > 0.5: 多想`（专家03 §2.4 line 95 明令）。**允许形态**：相对自身近窗统计的超出量（统计量、非拟合、非人设）。
- 注意：本引擎自主拍"自态变化太小"会导致**没东西可学**（`内核_自模型.py:37-39` 的 ⑤）——故 `ε_att` 的分离必须在**有输入 / 有候选竞争**的条件下测，不能只看空转。

## 4 与 ĝ 的关系：ε_self 与 ε_att 是**两条独立误差**吗？如何避免冗余

**结论：是两条独立误差，且独立性有结构根因，可实测证伪。**

1. **靶的生成因不同（外生 vs 内生）**：
   - `ε_self` 的靶 `S_{t+1}=sign(H_{t+1})` 由**外感输入 u** 决定（`内核_自模型.py:19-21`）。→ 外生。
   - `ε_att` 的靶 `A_{t+1}=sign(Φ_act@a星_{t+1})` 由**动作选择/内生偏置**决定：`a星` 是 `动作候选[efe选i]`（`hdc_core.py:482`），选择受 `内生偏置 b` 调制（`hdc_core.py:391`；`synthesis.py:519-535` 用 `私偏κ` 与 `消化债`写 `b[1]/b[3]`）。→ 内生。
   - **两个靶由不同的因驱动** ⇒ 两条误差在本体上就不是同一件事。
2. **同一份动作，对一个靶是噪、对另一个靶是信号**（这是最硬的排冗余证据）：
   - 对 ĝ：文件头实测 `S_t⊛a_t→S_{t+1}` 仅 **0.600/ε=0.800**（动作对"状态"是**纯噪**，`内核_自模型.py:17-21`）。
   - 对 ĝ_att：下一拍注意由 `a_prev` **闭环**决定（`v2_engine.py:252-253` 用 `a_prev` 作 `a_供数`，`:302` 推进 `_a_prev`；`hdc_core.py:418` 键含动作候选）⇒ 动作对"注意"是**信号**。**同一变量一靶为噪、一靶为信号 ⇒ 无法互相代替。**
3. **如何实测"不冗余"（可失败）**：
   - **残差判别**：把 `ε_att` 对 `ε_self` 做偏回归（`ε_att − proj_{ε_self}(ε_att)`），残差仍须对"熟悉/陌生"有判别力（AUC > 0.5）。
   - **相关门**：`|ρ(ε_self, ε_att)|` **不得逼近 1**；若相关 ≈1 ⇒ 携带同一信息 ⇒ **冗余 ⇒ FAIL**（如实登记，并考虑退回单路）。
4. **实现层面去冗余**：`W_att` 与 ĝ 的 `W`（以及专家02 的 `W_self`）**三块物理分离**；迹**各自独立**；注意空间（经 `Φ_act`）与状态空间（`H双极`）**不同投影域**。
5. **与 `W_self`（简报 P2）的分工**：`W_self` 是"我"的**自指联想**（`内核_自我回路.py:84,119-134`，当前是**死存储**，属专家02）；`W_att` 是"我**注意如何转移**"的联想。**二者结构性同款、语义不同**，本方案**不**去读 `W_self`，以免与专家02 撞车。
