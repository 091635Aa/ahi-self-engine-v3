## 1. 接线拓扑

### 1.1 新第七层放在「六层链之顶（H 之上）」

现状链（`内核宿主.py:13-19, 45-54`；`内核_画面.py:74` 自注 "六层链 H←W←Z←L←T←基"）：

```
synthesis.综合体(基) ← 自模型(顶覆盖_综合体) ← T(顶覆盖_综合体T) ← L(顶覆盖_综合体L)
                     ← Z(顶覆盖_综合体Z) ← W(顶覆盖_综合体W) ← H(顶覆盖_综合体H) ← ★M(顶覆盖_综合体M)
```

**为什么放顶不插中间**：①H 是当前链顶（`内核宿主.py:67`）；②每层范式都是「**只加挂 `_引擎步` + 旁挂失败 `try/except pass`**」（`内核_自我回路.py:250-256`、`内核_顿悟涌现.py:250-277`、`内核_画面.py:851-858`）；③插中间会截断上层 `super()` 链（`内核_画面.py:700-701` 已就此警示过一次）。

类声明的**形状**（镜像 `内核_自我回路.py:154-177, 250-256` 与 `内核_画面.py:697-724, 851-858`）：

```python
class 顶覆盖_综合体M(顶覆盖_综合体H):          # 必须在 H 之上；链保持线性
    def __init__(self, seed=310, 私偏κ=10.0, 元自我开关=None, 档案seed=None, 学习=True, **既有形参…):
        # ★先置属性——super().__init__ 期间 _引擎步 已被调用（synthesis.py:89 注释；内核_自我回路.py:165-167）
        self.元自我开关 = bool(开关默认 if 元自我开关 is None else 元自我开关)   # 开关默认=False
        self.元自我核 = None
        super().__init__(seed=seed, 私偏κ=私偏κ, 档案seed=档案seed, 学习=学习, **既有形参…)
        if self.元自我开关:
            self.元自我核 = 元自我核(D=…, 档案seed=int(seed if 档案seed is None else 档案seed))

    def _引擎步(self, u):
        rec = super()._引擎步(u)                      # 基链状态推进 + 步2~7 旁挂，逐行不变
        if self.元自我开关 and self.元自我核 is not None:
            try:
                self._元自我一拍(rec)
            except Exception:
                pass                                  # 旁挂失败绝不打断既有路径（同 内核_自我回路.py:255-256）
        return rec
```

**关键纪律（复刻既有成功范式）**：
- 顶层必须**显式声明** `元自我开关` 形参（`内核_画面.py:709-713` 的影子）——否则 `造桥(**开)` 传 `元自我开关` 会 `TypeError`（H 的 `__init__` 无 `**kw`，见 `内核_画面.py:709-712`）。
- `元自我核` 构造必须在 `super().__init__` **之后**（构造期 `_引擎步` 已跑，此刻 `元自我核=None` ⇒ 自然跳过，不改任何状态）。
- 元自我核**不得 import 任何器官**（`内核_自我回路.py:19`、`内核_画面.py:43` 同律）。

### 1.3 开关如何加入 `内核宿主.开关`

现状（`内核宿主.py:50-54`）：

```python
开关 = dict(自模型开关=True, 思核开关=True, 学习开关=True, 自我开关=True, 顿悟开关=True,
           自我提问开关=True, 画面开关=True)          # 7 键（V3 自我意识配置，全开）
```

**接法**：在 dict 尾部新增键 `元自我开关`，经 `造桥(**开)` 透传到链顶 M 的 `元自我开关` 形参（`造桥` `**开` 于 `:67-68`）。

**取值纪律（C14 的落地）**：
- **本轮先置 `元自我开关=False`**。理由：`造桥()` 被 `V3生命.起综合体()` 调用（`test_模块五_五内核.py:86-88` 即走此路），若默认 True 会让 M 层在 N5-2..N5-8 与模块六里**突然激活**，可能漂移既有读数——这是**开放新开关的已知风险**。置 False 则 `造桥` 默认输出与既有**逐位恒等**（§1.4 证）。
- 功能由**显式传参**开：`造桥(seed=310, 开关_={"元自我开关": True})`（`内核宿主.py:57,65-66` 已支持 `开关_` 覆盖）。
- **待全量回归确认零漂移**（§4.1 全绿）之后，Lead 再决定是否把该键随"V3 六层配置"置 True；**一旦 N5-x/模块六读数漂移即回退 False**（§5 回退线）。
- 内核侧纪律不变：`内核_元自我.开关默认 = False`（同 `内核_自我回路.py:47`、`内核_画面.py:78`）。
