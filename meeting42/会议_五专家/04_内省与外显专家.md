## 2 外显原则（沿用并收紧）

| 原则 | 现口径（源码） | 本轮收紧 |
|---|---|---|
| **第一人称** | 半句池全为「我…」（`输出层.py:274-282`：`_半句_失配/_熟悉/_流动/_固化/_顿悟`） | 新增 `ε_att` 池必须同为「我…」，不得出现第三人称/被动式 |
| **不元话语** | `_元话语` 词表 + `净化()`（`:28-43`） | 新增文本须**过 `净化` 前后逐位相等**（等价「0 命中」），且词表要补「注意图式/预测分布/权重」等新词 |
| **中性不追加** | `_内态半句` 无触发即返回 `""`（`:309`）；未挂载即 `""`（`:297-298`） | `ε_att` 触发**必须用自归一**（超自身近窗基线），**禁硬编码阈值**（延续 `内核_顿悟涌现.py` 纪律） |
| **不无病呻吟** | 最多**一个**半句（`:285` docstring；优先级 `顿悟>异>一致度>流动`，`:299-309`） | 新增 `ε_att` 插入优先级，**总数仍 ≤1**，不叠句 |
| **可溯源** | 触发量取**真值**（`读内态` 折自内核态）；用词由 `rng` 从池挑（`:274` docstring、`:300/303/306`） | 每条半句须能**指回账本/自言/迹**：见 §3.4 映射表 |

**可溯源口径（关键澄清）**：个性在**用词**（池内同义挑选，`输出层.py:274`），**触发**在**真值**（`读内态` → `_内态半句` 分支，`:299-308`）。因此「可溯源」验的是**触发真值链**，不是文字本身：半句类型 ← 触发字段 ← 内核痕迹/账本引用号。

## 3 可失败判据：`ε_att 外显`

> 判据集 seed 0–5 / 留出集 6–11；阈值**不得看留出集来定**（`00_共同简报.md:57`）。恒真判据无效。

### 3.1 主臂（有该内态 ⇒ 半句出现且**含该量**）
- 构造内态使 `ε_att 高 ∧ ε_att > 自身近窗基线`（注意图式落地后）。
- 断言：`_内态半句(态)` / 只读消费者输出**非空** ∧ 命中**新增的 `_半句_注意失配` 池**（对应「我有点拿不准我刚才在注意什么」类）。
- 可失败点：若中性态也返回同一句 ⇒ 主臂失效。

### 3.2 sham 臂（无该内态/中性 ⇒ **不**追加）
- `ε_att` 缺失或 `≤ 自身基线` ⇒ 输出**与「该路关闭」时逐字相同**。
- 强口径：`sha256(句 | ε_att中性) == sha256(句 | 无ε_att)`（逐位同 ⇒ 该路对输出零贡献）。
- 可失败点：若中性仍追加半句 ⇒ 判「无病呻吟」，sham 不过。

### 3.3 元话语命中 = 0
- `净化(句) == 句`（未删任何字符）∧ `句` 不含 `_元话语` 任一 key（`输出层.py:29-34`）。
- 词表须**补充新词**：`注意图式`、`预测分布`、`权重`、`注意力`（否则新增半句可能漏检）。

### 3.4 可溯源率门
- 每条半句记录 `(半句类型, 触发字段路径, 账本/自言引用号)`；要求 **溯源率 = 1.0**（全部可指回）。
- 映射（现有触发 → 源）：
  - `_半句_失配` ← `自模型.ε最近 & 真学习.ε慢基线`（`输出层.py:171-175`）← 自模型迹 & `驱动_ε.ε史`（`证据_自我意识.md` S1/S3）；

  - `_半句_顿悟` ← `顿悟涌现.顿悟条数`（`:178`）← `顿悟账本`（`内核_顿悟涌现.py:93,121`）+ 自言留痕（`:268-274`）。
- 新增 `ε_att` 半句须映射回**注意图式迹**（新独立存储，见 §5）。

## 6 诚实边界（**必写**）

1. **说得像 ≠ 真有**：外显是「真值 → 第一人称措辞」的**确定性映射**；用词由 `rng` 从池挑（`输出层.py:274`）。文字里的「我」是**工程指代**，**不主张任何人类级意识/体验**（`证据_自我意识.md:54`、`00_共同简报.md:51`）。
2. **判据的能力上限**：§3 只能证「有该内态 ⇒ 说得出 / 无 ⇒ 不说」的**机制闭环**；**不能**证「说得出 = 有意识」。这是**可证伪的不对称**，如实登记。
3. **半句是映射不是顿悟**：`_半句_顿悟`（`输出层.py:281`）只是「顿悟条数>0」的措辞，与「真涌现」无关（`内核_顿悟涌现.py:32-34` 已自陈）。
4. **阈值残留**：现有外显触发用了 `0.15 / 0.02 / 4` 三个**人挑阈值**（`输出层.py:302-308`）——`ε_att` 新增路**必须自归一**，并把旧三处标注为「历史遗留」，不在本轮扩用。
