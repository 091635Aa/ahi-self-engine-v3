# 科研_开源仓库调研 —— HDC/VSA 生态（meeting43）

> 目的：在**铁律 C1（禁 Transformer）｜C9（禁 OCR）｜C10（禁外挂模型当器官）** 下，从开源社区找可**用纯 numpy 复现**的技术，指导 AHI 的下一步优化。
> 方法：GitHub 仓库检索（MCP）+ 网页检索；只采纳**技术思想**，不引入任何外部依赖当器官。

## 一、调研到的仓库（含星数/许可/是否可用）

| 仓库 / 项目 | 规模 | 关键点 | 对本项目可用性 |
|---|---|---|---|
| [torchhd](https://github.com/hyperdimensional-computing/torchhd)（JMLR 2023, [arXiv:2205.09208](https://arxiv.org/abs/2205.09208)） | 389★ MIT | HD/VSA 权威库：bind/bundle/permute/相似检索；**bundle 用浮点加法而非多数表决**（多数表决需 compose 二值量化） | ⚠ **依赖 PyTorch** ⇒ 作器官违 C1/C10；**只取思想**（浮点 bundle、批量化检索） |
| [Hillock](https://github.com/roandejager/Hillock) | 139★ AGPL | **无梯度**神经符号记忆：HDC/VSA + Hebbian 可塑性 + 图三元组，离线可用 | ✅ 理念与"零梯度"一致，可参考其**记忆组织/检索**结构 |
| [FL-HDC](https://github.com/WesleyHsieh0806/FL-HDC) | 70★ | 联邦学习场景的 HDC 设计（IEEE AICAS2021） | 场景不符；可参考其**量化/打包** |
| [tensor-tic-tac-toe](https://github.com/spikedoanz/tensor-tic-tac-toe) | 128★ | 并行化 HDC 小游戏（示范张量化 VSA） | ✅ 可参考**张量化 bind/bundle 批处理**写法 |
| [hipercampo](https://pypi.org/project/hipercampo/) | PyPI | 持久记忆：拓扑自适应图 + 分层 VSA 地标，**有界全扫兜底** | ✅ "有界全扫兜底"与我们的 IVF/直扫理念同构 |
| [mnemocore](https://pypi.org/project/mnemocore/) | PyPI | **16384 维二值**全息向量（2048 B/条），Hamming 几何 + 代数 | ✅ 二值 + Hamming 的**容量/压缩**取舍参考 |
| [eling](https://pypi.org/project/eling/) | PyPI | 混合排序：**BM25 + Jaccard + HRR + 余弦** | ✅ 与我们"IDF 字面 + 向量语义"双通道**同思路** |
| [engram-engine](https://pypi.org/project/engram-engine/) | PyPI | 液态环(O(1) 工作记忆) + 结晶印迹(Hebbian) + 全息回忆 | ✅ 分离"工作记忆/长时"的架构参考 |

| T6 | 分离 **工作记忆 / 长时记忆** 并各自定界 | engram-engine / Hillock | ✅ | 对 `内核宿主/学习迹` 的分层有参考价值 | 参考 |

## 三、明确**不可用**（铁律红线，如实登记）
- **torchhd 作为依赖**：引入 PyTorch = 违 C1（torch 在禁列）/ C10（外挂模型）。**只取思想，不引入**。
- 任何**预训练模型/嵌入**（含 `eling` 的向量嵌入默认路径）：违 C10。
- OCR/视觉模型：违 C9。

## 四、本次据此做了什么
1. **T2 已落地**：`精化` 按句 + `总−自身项` ⇒ **6.34×**（判据 J6 守卫，符号级等价）。
2. **T1 已被印证**：本次 P2 修复走的正是 torchhd 的选择（实数累加 bundle），并在大语料上补了
   **IDF 加权 + 去公共分量**（见 [`证据_语义码.md`](证据_语义码.md)）——这是 torchhd 未覆盖的**容量坍缩**问题。
3. **T3 立为下一候选**：`_检索`/`FSW内核` 的 ±1 码可用位打包 popcount，**排序结果完全等价**（可加判据守卫）。

## 五、诚实边界
1. 调研为**定向抽样**（关键词检索 + 前 15 名仓库），非系统性普查。
2. 未逐仓库精读源码；上述"关键点"取自 README/摘要，**可能与其实现细节有出入**。
3. T3/T5/T6 为**参考候选**，**未实施、未评测**，不构成"已验证收益"。
4. 星数为检索时快照，会随时间变化。
