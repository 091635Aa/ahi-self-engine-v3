# AHI 自主智能引擎 · V3（视觉项目：全屏视场 + 教会用电脑）

> **AHI（Autonomous Human-like Intelligence，自主智能引擎）** 是一个从**第一性原理**构建的
> **非 Transformer** 自主智能体。本仓库是 **V3** 精选开源版，**承接 V2 的"给引擎一个世界"主线**，
> 主打两件事：**① 真正的视觉**（全屏视场 + 焦点加权，真的看清整屏）＋ **② 教会它用电脑**
> （左键/右键/中键/滚轮/键盘——自主探索学习，不是写死流程）。
>
> ⚠️ **路线声明**：**禁 Transformer（C1）、禁 OCR（C9）、禁外挂模型当器官（C10）**。
> 视觉走"中央凹流 + 色无关形状束 + 图标簿 + 直达 + RPE 多巴胺"的原生通路，不是用现成 CV 模型贴上去。

---

## 这个仓库是什么

V3 = **AHI2.1 整包 + 四大模块 + meeting39 六内核（真接线）+ 主程序 + meeting41 第七轮 + 测试证据**。

从 V2 的"自我/非我需要世界"这一收窄结论出发，V3 把动作落在真实世界接口上：

- **四大模块**：思考不公布 / 操作干净化 / 视觉看网页 / 学习强化（学习 ≠ 记忆）；
- **六内核**：自模型 ĝ、相空间算子 T、真学习、自我回路、顿悟涌现、**画面（视觉想象）**；
- **第七轮（meeting41）**："能力核 + 操作熟练 + 同时进行"——能力对标 Transformer，但**保留禁 Transformer 红线**；
  学习操作 15 秒→10 秒→5 秒→3 秒（允许反弹），边思考边操作，思考流程和手上不断。

## 核心判据要览（来自第七轮 三层，全部可复跑）

| 层 | 落件 | 实测读数 |
|---|---|---|
| L1 能力核 | `算子_能力核.py` | 线性时间 计费(4096)/计费(1024)=**3.999918**（sham 二次=16.0 判不过）；长程依赖命中率 **1.0**（sham 0.1）；未定义令牌 3/3 非零两两不同；W 码跨 3 个 `PYTHONHASHSEED` 逐位同 |
| L2 操作熟练 | `技能原子.py` 等 | 档位 150/100/50/30 拍 = **15/10/5/3 秒**；训练 4 轮到达 3 秒；反弹 ⇒ 加练；对照臂停 15s |
| L3 同时进行 | `输出流.py` 等 | 最大空隙拍 **1**（≤2）、思考跨操作 **120**（>0）、孤立动作 **0**、覆盖率 **1.0** |
| 效率判据 | `判据_效率.py` | E1/E2/E3 真件读数，sham 全部判不过 |

## 怎么跑

```bash
pip install numpy torch scikit-learn

# 四模块 + 六内核 一条龙演示（看网页 → 学 → 操作规划 → 说话）
python V3主程序.py
# 画面演示：看一屏 → 从记忆里读出画面 → 把记忆里的东西搬到新位置（落 PNG）
python V3主程序.py --画面
# 真实刷网页（默认搜狐首页）：看 → 学 → 消化 → 喂引擎 → 说话
python V3主程序.py --刷网页 https://www.sohu.com/ https://news.qq.com/
# 真自主运行 N 拍（六内核全程在链上：自己出招 / 自己发问 / 自己想画面）
python V3主程序.py --自主 2000 --自主网页
python V3主程序.py --自主 1200 --自主想象 --想象间隔 300
```
