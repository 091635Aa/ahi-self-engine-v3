## 2 流式语音与自听缺口（证据链）

### 缺口 1｜`声带.py` 无流式 API（整句批处理）
- `meeting32/声带.py` 全文 `流式`/`yield` = **0 hits**；公开 API 为 `发声(self, 向量, 文本, 遥测=None) -> dict`（:478），一次返回整句 wav。
- 内部其实已有**帧级/音节级**分解：`帧率=100`（:28）、`音节帧(文本,律,qs)`（:249）、`合成波形(帧)`（:365）→ 流式化在数学上可行，但**无跨调用状态**（相位/谐振器/F0 连续）。
- 结论：E2 §2①「新增 `声带_流式.py`」、E3 §2②「新增 `流式声带.py`」可行；E5 §3「抽 声带.py 相位/谐振器为跨调用状态」将**触碰既有 .py**，与 C14 冲突（见 §4）。

### 缺口 2｜`器官_嘴.py` 未接真声带（走 SAPI/pyttsx3）
- `meeting38/器官_嘴.py` 全文 `声带` = **0 hits**；后端为 Windows SAPI（:73,:99）或 pyttsx3（:79-80），失败降级打印。
- `说()` 仅入队（:176），`发声子线程`（:129）内 SAPI `Speak` **同步阻塞**（:149）→ 无帧级提交栅栏，已开口不可改、打断不可行。
- 结论：E5 §6「SAPI 整句 Speak 与声带整句批处理均无帧级提交栅栏」**属实**；E1/E2/E3 的流式与打断判据在接线前**必失败**。

### 缺口 3｜自听静默失效（`耳.听/耳.学` 不存在）
- `声带.py:593 接综合体(桥, 耳=None)` → :616 `听到 = 耳.听(rec["波形"])`、:617 `耳.学(听到, 响)`；
- 但 `meeting38/器官_耳.py` **无 `听`/`学` 方法**（`def 听`/`def 学` = 0 hits），仅 `一块`(:202)/`运行`(:230)；
- 异常被 :619 `except Exception` 吞掉并写 `声带异常.log`（:620-624）→ **自听静默失败**。
- 结论：E2 §1「[已实现][待验证] 接综合体 调 耳.听/耳.学 但 器官_耳 无此二法→异常被吞→自听静默失效（E5 已证）」**完全属实**；E2 §2③ 的 `耳_接听.py`（补 听/学）是必要前置；E5 §3 同指认。

### 缺口 4｜安全现状 fail-open（不可逆无执行端闸）
- `meeting38/安全事实.py:14`：「任何失败 → 返回空串（该次查询上安全闸退化…）」；全文 `不可逆` = **0 hits**。
- 结论：E1 §3「现有脑危词闸『事实源异常→放行』是 fail-open（test S5）」与 E5 §2③「不可逆须执行端最后一米闸＋单次许可令牌」**属实**；不可逆 fail-closed 需新增（手 `_执行键`:315 前校验）。

### 缺口 5｜节奏口径不一致（手 vs 功能档案）
- `器官_手.py`：`减速半径 = 160.0`（:52）、`到达门 = 2.0`（:54）、`到达停顿 = 0.25`（:55）、`抖动σ = 0.35`（:57）；
- `功能档案.py`：`节奏()`（:213）线性减速用 `d/400.0`（:222）、`到达停顿 = 0.2 if d<=20`（:225）。
- 结论：E5 §3「现有 减速半径 160/到达停顿 0.25 与档案 0.2 两套口径需统一」**属实**（且档案线性半径为 400，非 160）。

### 缺口 6｜输出层现读 M/得分，未读 R
- `输出层.py:181` 入参为 `M检索结果`；:203 `记["分"] >= 0.2` 判命中；`文本态.py:169` 打印相似 → 与 C-R2-8 冲突（见 §1）。
- 结论：E1 §3「纯追加 生成正文_R，原入口不动可回退」是**唯一不破 C14** 的接法。
