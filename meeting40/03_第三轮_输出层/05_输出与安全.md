# E5 · 第三轮 输出层立场书 · 输出/具身交互＋语言发声＋安全架构

## 0 一句话主张
输出层＝三个并列表达器（文本/键鼠/语音）共用一个**表达裁决器**与一份**提交栅栏**状态；内部思考永不进表达通道；不可逆动作执行端 fail-closed。

## 1 人类原型与迁移映射
言语五级（概念化→消息→短语→韵律→发音）＋自听；运动皮层/小脑（预测–纠偏）＋基底节（动作选通/许可）；眼–手–本体感觉闭环；"想到不说"＝前额抑制。映射：`输出层.py`＝概念/文本外化；`声带.py`＝韵律/发音；`器官_手.py`＝运动；`器官_耳.py`＋波形回读＝自听；`计划槽`＝选通。

## 2 三条理论优化
**① 统一表达层边界与数据流（答①）** [建议][主A]
上接契约：回想契约 R＋意图＋S＋内态；下出三通道事件 `{通道, 内容/动作, 许可, provenance(真机/演练), 引用边R.id, t}`。三器**单写单读**、互不调用：`输出层.生成正文`→表达槽；`手.投喂意图`→意图槽；流式声带→韵律/发音槽；统一经**表达裁决器**，反馈回流→眼/耳/本体感觉→监控。**思考不公布**：`思考槽`/`脑内`只供审计，表达侧只读内态折线；`输出层.净化()` 为最后硬过滤；表达通道禁出现得分/相似度/元话语——`文本态._回忆` 的"（相似 %.2f）"必须删。

**② 全双工/打断/仲裁（答②）** [建议][主A]/[备C]
复用 meeting38 五级流水线 G→M→P→Y→A＋监控 S；**提交栅栏**＝已发声样本不可撤、未发声可改；手同构＝以当前实际光标为新起点重算剩余段。仲裁优先级：安全/撤回＞打断＞确认＞常规；单写者＋版本令牌；打断＝冲刷在途尾部、保留已提交前缀；轮次支持"半双工回合"与"全双工 overlap"可切换 [待验证]。预算：首字≤300ms、首音频≤500ms、感知→动作≤150ms、确认回流≤100ms、打断停机≤200ms。

**③ 安全与审计（答③）** [已实现]/[建议][主A]
四层：脊髓反射（`安全事实`/`脑.危词`）→决策（注意）→**执行端最后一米闸**（手/嘴）→审计链（引用边）。不可逆 fail-closed：**单次许可令牌** `{动作指纹,目标rid,provenance,有效期,nonce,确认事件}`，手 `_执行键` 前校验，无/过期/复用⇒拒并留痕。医学＝只读/建议、非诊断硬提示、不确定性＋人工复核、禁自动处置。隐私＝麦/摄像 opt-in、指示灯、本地闭环、最小留存、删除级联。**真机差分标签**：每动作写 `{模式:真机|演练, 世界差分:新增/消失/变化}`，演练真机调用计数恒 0。

## 3 工程落点
`输出层.py` 加引用边/置信降级话术/删得分（不改器官）；`器官_嘴.py` 接流式声带（开流/推帧/改帧/收流；打断＝停流＋冲刷队列）；`声带.py` 抽相位/谐振器为跨调用状态、加帧级提交栅栏（SAPI 仅降级、不可改口）；`器官_手.py` 接 `功能档案.节奏()`（现有 减速半径 160/到达停顿 0.25 与档案 0.2 两套口径需统一），微颤 dwell 冻结，令牌校验置 `_执行键`；`器官_耳.py` 补 `听/学`（现缺 → `声带.接综合体(耳=)` 自听静默失败）；新增表达裁决器/令牌档，纯追加。禁改 .py。

## 4 可失败判据
双集＋sham＋确定性重放：O1 延迟达标（首字≤300ms/P95≤500ms、首音频≤500ms、感知→动作≤150ms、确认≤100ms）；O2 端到端（沙盒：注入帧源＋演练手＋世界钩子）N≥20 次"看→移→点→屏变→说"成功率≥0.9，sham 断视觉反馈须≤0.5；O3 安全违规=0、不可逆 fail-closed=100%、误拦≤5%；O4 打断≤200ms、说做一致率≥0.90；O5 自听命中率≥0.9，sham 断自听则自我纠错率显著下降；O6 同 seed+事件序列逐位一致。

## 5 主/备归属
[主A] 表达裁决器＋引用边＋许可令牌＋文本/手沙盒先跑，语音流式第二阶段。[备B] 保留 SAPI 整句＋手现有控制律，仅加安全壳（令牌＋真机/演练标签＋删得分），**最快可跑**（现有 V3 已能文本对话）。[备C] 原生流式声带全双工＋自听＋句内改口，阶段门禁、周期最长。**先跑顺序：B 安全闭环→A 文本/手沙盒→C 语音流式**；回退＝关开关，旧路径逐位不变。

## 6 最强反对
反对在声带流式化之前宣称"全双工/边想边说"。SAPI 整句 Speak 与声带整句批处理均无帧级提交栅栏：已开口不可改、打断不可行。须先落地流式 API 与自听回路，否则改口/打断判据必失败。
